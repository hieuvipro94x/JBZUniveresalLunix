3. SỬA ROOT CAUSE SQLITE
============================================================

Tìm các SQL/index/query trên bảng Tests có dạng sai:

COALESCE(TestStartedAt, Started)

ORDER BY Started

WHERE Started

INDEX(... Started ...)

Nếu thao tác trên bảng Tests thì phải dùng:

StartedAt

Ví dụ đúng:

COALESCE(TestStartedAt, StartedAt)

Nếu cần index History:

CREATE INDEX IF NOT EXISTS IX_Tests_HistoryAt_Id
ON Tests(
    COALESCE(TestStartedAt, StartedAt) DESC,
    Id DESC
);

Nếu cần Part/Inspection:

CREATE INDEX IF NOT EXISTS IX_Tests_Part_Inspection_HistoryAt_Id
ON Tests(
    PartId,
    InspectionType,
    COALESCE(TestStartedAt, StartedAt) DESC,
    Id DESC
);

Không được còn:

COALESCE(TestStartedAt, Started)

trong SQL của bảng Tests.
