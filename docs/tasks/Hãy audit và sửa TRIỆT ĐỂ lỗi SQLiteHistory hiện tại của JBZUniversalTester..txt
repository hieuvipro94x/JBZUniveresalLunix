Ví dụ hợp lệ:

Ngày/Thời gian trên History phải dùng:

EffectiveTestStartedAt =
TestStartedAt ?? Started

Trong DB tương đương:

COALESCE(t.TestStartedAt, t.StartedAt)

History phải sắp xếp:

MỚI NHẤT
→ CŨ NHẤT

tức:

ORDER BY
    COALESCE(t.TestStartedAt, t.StartedAt) DESC,
    t.Id DESC

Không quay lại ResultAt nếu requirement hiện tại đã chốt theo thời điểm bắt đầu test.

5. FILTER THỜI GIAN PHẢI CÙNG NGUỒN
======================================================================

Nếu UI hiển thị ngày theo TestStartedAt/StartedAt thì filter ngày cũng phải dùng cùng timestamp.

Ví dụ:

FromDate <= COALESCE(TestStartedAt, StartedAt)
< ToDateExclusive

Không được:

UI hiển thị TestStartedAt
nhưng filter bằng ResultAt

vì sẽ tạo trường hợp record nhìn thuộc ngày A nhưng query lại thuộc ngày B.

Audit:

ConfigureHistoryFilter(...)

From
To

và thống nhất semantics.

======================================================================
6. KEYSET PAGINATION PHẢI ĐỒNG BỘ
======================================================================

Hiện History dùng keyset pagination.

Nếu sort key đổi sang:

COALESCE(TestStartedAt, StartedAt)

thì cursor cũng phải dùng CÙNG key.

Không được:

ORDER BY TestStartedAt
nhưng cursor BeforeResultAt dùng ResultAt.

Nếu model hiện có field:

BeforeResultAt

nhưng semantics mới là History timestamp,
có thể:

A. đổi tên thành BeforeHistoryAt / BeforeTestStartedAt

nếu không gây ảnh hưởng lớn;

hoặc

B. giữ tên cũ để tránh scope change nhưng phải document rõ semantics.

Ưu tiên code rõ ràng nếu thay đổi an toàn.

Cursor phải tương đương:

historyAt < cursorHistoryAt

OR

historyAt = cursorHistoryAt
AND Id < cursorId

với:

historyAt = COALESCE(TestStartedAt, StartedAt)

Page 1 + Page 2 không:
- duplicate
- mất row
- đảo thứ tự.

9. LEGACY DATABASE COMPATIBILITY
======================================================================

Rất quan trọng.

Self-test có:

Legacy SQLite without SchemaInfo initializes safely

Do đó phải test database cũ chưa có:

TestStartedAt

hoặc schema version cũ.

Không được tạo index expression trên column chưa tồn tại TRƯỚC khi migration/add-column hoàn tất.

Thứ tự initialization phải là:

1. create/read schema cơ bản
2. add missing columns
3. migrate
4. sau khi chắc column tồn tại mới create index mới.

Nếu CreateSchema hiện create index dùng TestStartedAt trước EnsureColumn,
hãy sửa thứ tự.

Không được để database v4/v5 cũ mở app là crash.
